# Voice Chat 人设模板 · 使用说明书（DeepSeek 版 · 网页端）

*适用于完全不懂代码的用户 | 只需替换【】内容即可拥有专属 AI 语音聊天角色*

---

# 一、这个文件是什么？

这是一个 **AI 语音聊天网页**。打开后，你可以和一个自定义的 AI 角色用文字、语音、甚至视频通话的方式聊天。

**完整功能列表：**

| 功能 | 说明 |
|---|---|
| **文字聊天** | AI 同时用英文和中文回复，英文部分自带语音朗读 |
| **语音通话** | 像打电话一样和 AI 角色说话（实时对话） |
| **按住说话** | 按住麦克风说话，自动转文字发送 |
| **语音消息** | AI 的每条回复都能点「再听一次」重播 |
| **长期记忆** | 跨对话记住聊过的事，不会每次失忆 |
| **日记系统** | AI 角色每天晚上 20:00 自动写当天日记 |
| **主动消息** | AI 会主动找你聊天（可开关） |
| **表情包** | AI 会根据情境发你准备的表情包 |
| **小游戏** | 海龟汤、真心话大冒险、故事接龙、一起做饭 |
| **喂食** | 给 AI「喂」东西吃，看它反应 |
| **换装** | 递给 AI 一件衣服，看它穿不穿 |
| **看屏幕（视监）** | AI 能「偷看」你的屏幕并做出反应 |
| **经期日历** | 记录经期，AI 会贴心关怀 |
| **一起听歌** | 播放本地音乐，AI 能看到歌单、能帮你切歌 |
| **角色扮演** | 可临时切换到另一个角色/剧本 |
| **联网搜索** | 问时效性问题时自动联网 |
| **回复条数控制** | 限制 AI 单次最多回几条，省 token |
| **拉黑** | 拉黑 AI 后它会主动来求和哄你 |
| **搜索聊天记录** | 快速找到之前说过的话 |
| **多主题换肤** | 切换界面配色 |

你拿到的是一个**空白模板**，所有的角色设定（名字、性格、说话方式、外貌、语音）都需要你自己填入。本文档会一步步教你怎么做。

# 三、记忆库文件夹怎么建（重要）

「记忆库」是让数据持久保存的关键。不开记忆库，清缓存/换浏览器聊天记录就没了。

## 3.1 你需要手动建的

在电脑任意位置新建一个文件夹（**建议英文名**，比如 `MyAI-Memory`），然后**在它里面**再建两个文件夹：

```
MyAI-Memory/              ← 你新建的记忆库根文件夹（名字随意，建议英文）
├── stickers/             ← 你新建：放表情包
└── music/                ← 你新建：放音乐
```

**你只需要建这三个**，其余的程序会自动生成。

## 3.2 程序会自动生成的（不用管）

第一次连接记忆库后，程序会自动在里面创建：

```
MyAI-Memory/
├── stickers/             ← 你建的
├── music/                ← 你建的
├── memory/               ← 自动生成（chunks.json / vectors.json / meta.json / edges.json / buffer.json）
├── blobs/                ← 自动生成（语音、图片等二进制文件）
├── diary/                ← 自动生成（日记）
├── roleplay/             ← 自动生成（角色扮演存档）
├── chat-data.json        ← 自动生成（聊天记录）
├── settings.json         ← 自动生成（设置、API Key）
├── period-data.json      ← 自动生成（经期数据）
├── music-history.json    ← 自动生成（听歌记录）
├── custom-name.txt       ← 自动生成（你改的角色名）
├── custom-avatar.jpg     ← 自动生成（你换的头像）
└── current-outfit.jpg    ← 自动生成（当前穿搭）
```

## 3.3 表情包怎么准备

放进 `stickers/` 文件夹，要求：

- **支持格式**：`png` / `jpg` / `jpeg` / `gif` / `webp` / `svg` / `bmp`
- **推荐数量**：30~50 张
- **命名规则**：**文件名（去掉后缀）就是 AI 认识的名字**

举例：
```
stickers/
├── 得意.png        ← AI 会认识这张叫「得意」
├── 委屈.jpg        ← AI 会认识这张叫「委屈」
├── 吃醋.gif        ← AI 会认识这张叫「吃醋」
└── 想你.png
```

AI 发表情包时，会在回复里加 `"sticker":"得意"` 这样的字段，程序自动匹配同名文件显示出来。

> 💡 **所以命名要能描述画面内容**，比如「得意」「翻白眼」「求抱抱」，AI 才知道什么时候该发哪张。
> 别用「1.png」「图片001.png」这种，AI 不知道那是啥。

## 3.4 音乐怎么准备

放进 `music/` 文件夹：

- **支持格式**：`mp3`（推荐）/ `m4a` / `ogg` / `wav` / `flac` / `aac` / `wma` / `opus` / `webm`
- **命名**：建议 `歌手-歌名.mp3`，比如 `周杰伦-晴天.mp3`
- 开启「一起听」模式后，AI 能看到你的歌单，还能帮你切歌

## 3.5 怎么连接记忆库

打开网页后，点顶部 **「📁 记忆库」** 按钮 → 浏览器会弹出文件夹选择框 → 选中你建的 `MyAI-Memory` 文件夹 → 允许读写权限。

连上后按钮会变绿，之后所有数据自动存进这个文件夹。

> ⚠️ **浏览器要求**：这个功能需要 Chrome / Edge（Firefox 和 Safari 不支持）。

# 四、如何打开和运行

这个文件是一个单独的 `.html` 网页文件，不需要安装任何软件，不需要服务器。

## 4.1 电脑上使用

1. 找到你的 `deepseek模板.html` 文件（替换完人设后）
2. **双击打开**（会自动用浏览器打开）
3. 在弹出的页面中输入你的 API Key
4. 勾选「记住 Key」，这样下次打开不用重新输入
5. 点击「开始聊天」
6. 点顶部 **「📁 记忆库」**，选择你建的记忆库文件夹

完成！

> ⚠️ **注意：** 所有数据（聊天记录、Key）都保存在你的浏览器本地，**不会上传到任何服务器**。
> 换浏览器、清除浏览数据会丢失记录。**强烈建议开启「记忆库」功能**持久保存。

# 七、功能详解

## 7.1 回复条数控制（💬×N 按钮）

点顶部 `💬×N` 按钮可设置角色**单次最多回几条消息（1-20）**，随时可改。

- 这是**上限，不是必须发满**——角色心情不好可能只回 1 条
- 目的是省 token，让角色在限定条数内把话说清楚，而不是话说一半
- 主动消息也受这个上限约束

## 7.2 拉黑（🚫 按钮）

角色惹你生气了，可以拉黑它：

- 拉黑后**你不能发消息**（输入框禁用）
- 角色会**强制进入主动求和模式**：不管你的「主动消息」开关是开是关，它都会主动发消息来哄你/道歉/继续争辩
- 拉黑期间「主动消息」按钮会显示为「开」，点击会提示"拉黑中无法关闭"
- 再点一次「🚫 已拉黑」即可解除，一切恢复

## 7.3 联网搜索（🔍 按钮）

DeepSeek 官方 API **没有原生联网**，本版借用你填的 Key 实现：优先用 **Google Key**（免费），没有则用 **OpenAI Key**。开启后问时效性问题会自动联网。

> ⚠️ 两个 Key 都没填的话，联网功能无法使用。

## 7.4 模型切换

点顶部模型按钮可在 **V4-Flash（快、省）** 和 **V4-Pro（更强）** 之间切换。日常聊天 Flash 完全够用。

## 7.5 主动消息

开启后，AI 会在你沉默一段时间后主动发消息找你。AI 自己决定间隔时间（几分钟到几小时）。

## 7.6 日记

AI 每天 **20:00** 自动写当天日记，内容基于当天的聊天记录。点顶部「更多」→「日记」查看。日记存在记忆库的 `diary/` 文件夹里。

## 7.7 一起听歌

点「更多」→「一起听歌」，播放 `music/` 文件夹里的音乐。开启「一起听模式」后，AI 能看到你的歌单，会评论你在听的歌，还能帮你切歌。

## 7.8 看屏幕（视监）

点「👀 视监」按钮，选择要共享的窗口/屏幕。AI 会不定时「偷看」你的屏幕并做出反应（吃醋、心疼、好奇等）。你也可以说「看看我的屏幕」主动让它看。

> ⚠️ 这个功能只在电脑上可用，手机浏览器不支持屏幕捕获。

## 7.9 记忆库互通

**5 个模型版本（Claude / DeepSeek / Gemini / GPT / Grok）可以共用同一个记忆库文件夹。**

意思是：你今天用 DeepSeek 聊，明天换成别的模型，只要选同一个记忆库文件夹，聊天记录、长期记忆、日记、经期、设置全都在，等于随时换 AI 大脑但记忆不丢。

# 八、操作步骤总结

1. 用文本编辑器（VS Code / 记事本）打开 `.html` 文件
2. **先做全局替换：** `Ctrl+H` → 依次替换 8 个高频占位符（第 5.1 节）
3. **再逐个填写：** `Ctrl+F` 搜索「【」，找到剩余占位符逐一替换（第 5.2 节）
4. **补充歌词：** 搜索 `getRandomLyricFallback`，添加 20-50 条歌词
5. **填入 Voice ID：** 搜索 `VOICE_ID`，把 ElevenLabs 的音源 ID 粘贴进去
6. **建好记忆库文件夹**（含 `stickers/` 和 `music/`，见第三节）
7. **保存文件**，双击打开，输入 API Key
8. 点「📁 记忆库」连接你建的文件夹
9. 开始聊天！

> ✅ **验证方法：** 替换完后搜索「【」，如果除了角色扮演系统自带的（如【AI角色】【前情提要】等）之外没有剩余的【】，就说明全部替换完成了。

# 九、常见问题

**Q：打开后白屏 / 报错？**
A：确认用的是浏览器（Chrome / Edge）打开，不是 Word。如果替换时不小心删了代码的引号或括号，文件会出错——可以重新从模板开始替换。

**Q：AI 回复很奇怪 / 不像我设定的角色？**
A：检查 `SYSTEM_PROMPT` 部分的性格描述是否足够详细。描述越具体（给出说话示例、具体行为模式），AI 扮演得越好。

**Q：语音听不了？**
A：确认 ElevenLabs API Key 和 Voice ID 都填对了。Voice ID 是在 ElevenLabs 网站上选好声音后，点击声音卡片看到的一串字母数字。

**Q：聊天记录会丢失吗？**
A：聊天记录保存在浏览器本地。清除浏览器数据、换浏览器会丢失。**强烈建议开启「记忆库」功能**，选择一个本地文件夹作为持久存档。

**Q：记忆库按钮点了没反应 / 弹不出选文件夹？**
A：这个功能需要 **Chrome 或 Edge**，Firefox 和 Safari 不支持。

**Q：AI 不发表情包？**
A：确认 `stickers/` 文件夹在记忆库文件夹里，且里面的图片文件名是有意义的中文描述（如「得意.png」）。AI 平均每 10-15 条消息才发一次，这是设计如此，避免刷屏。

**Q：可以换角色 / 做多个角色吗？**
A：可以！把 `.html` 文件复制多份，每份填入不同角色的设定，**并且各自用不同的记忆库文件夹**，就能拥有多个独立角色。

**Q：我替换完了，但搜索「【」还能搜到很多？**
A：角色扮演系统自带一些【】标记（如【AI角色】【你扮演的角色】【存档读取成功】【前情提要】【重要】【marry】【hengry】【anger】等），这些是**系统内置的，不需要替换**。只要你的人设相关占位符都替换完了就行。

**Q：一个月大概花多少钱？**
A：DeepSeek（AI 大脑）非常便宜。ElevenLabs（语音）也便宜。OpenAI（语音转文字）按量计费。Google AI（记忆+联网）免费。整体是五个版本里最省的。

# 十、补充说明

## 10.1 UI 文案中的角色代词会自动替换

在做完高频占位符的全局替换后，以下几处界面文案也会自动被替换（因为它们同样使用了【角色称呼代词】占位符）：

- 偷看屏幕功能的气泡提示：**【角色称呼代词】偷看了你的屏幕**
- 故事接龙游戏描述：**你写一段【角色称呼代词】续一段**
- 一起做饭游戏描述：**【角色称呼代词】跟你一起做**
- 一起听歌功能描述：**和【角色称呼代词】一起听歌**
- 日记面板标题：**【角色称呼代词】的日记**
- 喂食面板：**喂【角色称呼代词】吃东西**

这些都包含在【角色称呼代词】的 32 次全局替换中，**不需要额外操作**。

## 10.2 双语说明

AI 的每条回复都包含 `english` 和 `chinese` 两部分：

- **english** → 喂给 ElevenLabs 做语音朗读（AI 说话的声音）
- **chinese** → 界面上显示的文字

**两个都不能删**。删了 english 就没语音，删了 chinese 就看不懂。

如果你想让 AI 说别的语言（比如日语），把 SYSTEM_PROMPT 里所有 `English` 改成 `Japanese`，并选一个日语的 ElevenLabs 音源即可。
